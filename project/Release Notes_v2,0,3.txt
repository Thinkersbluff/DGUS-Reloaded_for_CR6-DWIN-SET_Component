Last updated: 7 July 2026

New at release 2.0.3 - Stable:

New Features:
 - Bug fixes
 - Changed the versioning of the DWIN Component to match the Klipper Component version #.
 - Paired with the Klipper Component, this version now restores UI functionality which was disabled by Klipper3D updates which eliminated a variable that helped persist displays until all pending moves were completed.
 - Added the ability to "tell" DGU-Reloaded which type of filament you have installed.
   DGUS-Reloaded then uses that information + your presets, to enforce the filament-appropriate values of min-extrude temperature and default PID temperatures

Bugs fixed at this release:
97 - Change Filament LOAD/UNLOAD does not consider current Heater Target value
98 - Calibration Extruder Rotation Distance function is not working correctly
100 - The Change FIlament "Homing..." WAIT screen is not persisting until the function is complete
101 - Release 2.0.2 is incomplete - the Pull Request intended to push those changes was never merged.

Known Issues at this release:

 - No change since v0.4.3:

   - If you modify the Screen Brightness setting, Klipper may crash next time you issue a SAVE_CONFIG command.  This is an unfortunate behaviour of Klipper and not a bug in this firmware.  

   - If your Virtual SD Card contains any files which do NOT end in .gcode, the filelist should exclude that file.
  * If, however, while scrolling through the list, your system suddenly shuts down - check for any such files in ~/printer_data/gcodes. 
    Deleting those files should fix the problem.

   - The RESET and FIRMWARE RESET buttons on the splash screen do not work on power-up.
      They do work after a FIRMWARE RESET from the Mainsail Web client. 
     If, however, you install the local pi scripts bundled with the Klipper Component, you can configure your system to automatically restart Klipper when you power-cycle your printer, so this UI limitation no longer affects you.

 
CAUTION:

 - The FONT (.HZK) file changed at release v0.3.3.
	- If it is included in the DWIN_SET folder, it slows the flashing process
	- That file is in the "One-Time DWIN_SET files" folder
	- If you have not flashed it to your system before, you should copy that to DWIN_SET for one time
	- After flashing it once to the display, that file can again be removed from DWIN_SET
	- If you already flashed that file to your display, you do NOT need to flash it again.
 - The T5LCFG_272480K.CFG file in the "One-Time DWIN_SET files" folder must be flashed to your display IF AND ONLY IF this is the first time that you are flashing DGUS-Reloaded for CR6 to your display.

Cheers!
